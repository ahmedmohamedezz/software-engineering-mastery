# Structured Query Language (SQL)

- SQL was developed in 1970s by IBM, initially called SEQUEL

- SQL commands are often splitted into 3 parts: DDL, DML, DCL

1. data definition language
    - covers creation of DB tables & indexes
    - consists of 5 main statements: `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`, `CREATE INDEX`, `DROP INDEX`

2. data manipulation language
    - covers manipulation & viewing of data
    - consists of 4 main statements: `SELECT`, `INSERT`, `UPDATE`, `DELETE`

3. data control language
    - covers managing access, authorization, and ownership of objects in the database, as weil as procedural control statements.
    - consists of 4 main statements: `GRANT`, `REVOKE`, `COMMIT`, `ROLLBACK`
